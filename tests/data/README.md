# Datos de prueba

`nacl/`: ejemplo real de Phonopy con VASP (NaCl, supercelda 2x2x2, con BORN), tomado de la carpeta
`example/NaCl` del repositorio de Phonopy (licencia BSD-3). Se usa como prueba de regresión del lector
de fonones: verifica que los archivos reales se leen y que se aplica la corrección no analítica.
